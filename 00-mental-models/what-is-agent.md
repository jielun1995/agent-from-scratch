# 心智模型 1：Agent 到底是什么

## 一句话定义

> **Agent = LLM + 循环 + 工具 + 记忆 + 终止条件**

注意，不是"LLM + 工具"。很多教程到这里就停了，这是错的。**核心是"循环"**。

## 与普通 LLM 调用的区别

普通调用是一次性的：

```
你 → 提问 → LLM → 答案 → 结束
```

Agent 是循环的：

```
你 → 目标 → LLM 思考 → 决定动作 → 执行工具 → 观察结果
                ↑                                    ↓
                └────────── 再次思考 ←──────────────┘
                            (直到完成或放弃)
```

**这个循环就是 Agent 的灵魂。所有框架本质上都在做同一件事：优雅地管理这个循环。**

## 五行伪代码

```python
while 没结束:
    思考 = LLM(历史)
    if 思考说"完成了":
        return 答案
    工具结果 = 执行工具(思考里的工具调用)
    把工具结果加入历史
```

任何 Agent 框架，无论它包装得多花哨，核心都是这五行。
